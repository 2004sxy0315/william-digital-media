LATEST FIRST
03 VISUAL DESIGN Latest entry

Making the homepage feel more personal.

Moving from a basic introduction to a visual identity built around my name, portrait and creative interests.

What changed

I introduced a dark background, larger typography and orange accents. I replaced the original portrait with a higher-resolution photograph and used CSS gradients and colour adjustments to connect it with the page.

What I learned

Adding more decoration does not always improve a design. The bright rectangular photo initially competed with the text. Softening its edges and simplifying the surrounding shapes helped bring the focus back to the person.

What I want to improve

Check the portrait crop and text balance on smaller screens, then review whether the visual style feels consistent across the website.

02 SITE STRUCTURE

Giving each part of the website a purpose.

Using the About page as an overview, with separate spaces for experience, work and learning.

What changed

I organised the navigation around About, Experience, Work and Workshops. The About page introduces the whole website, while the other pages provide space to explore individual topics in more detail.

What I learned

A personal website needs to explain who I am as well as show what I make. Clear navigation helps visitors choose what they want to explore without putting every detail on the first screen.

What comes next

Keep the current Experience and Work pages for now. Develop their content after the overall structure and visual direction are settled.

01 BUILD & PUBLISH

Taking my first website online.

Building with HTML and CSS, then publishing through GitHub Pages.

What I made

I created linked pages in Visual Studio Code, added a shared stylesheet and uploaded the website files to GitHub.

What went wrong

My local changes did not immediately appear online. At another stage, a portrait failed to load. These problems made me check uploaded files, image paths and browser caching more carefully.

What I learned

Saving a file locally does not update the published website. HTML, CSS and images all need to be uploaded to the correct locations. A hard refresh helped me see an updated page after deployment.
